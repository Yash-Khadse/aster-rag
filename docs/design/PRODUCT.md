# Atlas

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Workspace members look up organizational information and verify answers against source excerpts. Owners, administrators, and authorized editors manage documents, access, and processing. Visitors can explore a demo workspace when enabled.

## Product Purpose

Atlas answers questions over documents the current user can access. Citations and source details let the reader inspect the basis for an answer. The library supports upload, search, document access, and job status. Search compares retrieval methods, and evaluations report recorded runs.

## Constraints

Keep workspace access rules, existing API flows, visible errors, and the distinction between real results and fictional demo data. Keep keyboard access and narrow-screen workflows usable.
